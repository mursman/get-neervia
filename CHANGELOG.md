# Changelog

All notable changes to Neervia are recorded here. Versions ship as releases
on this repository; the website always points at the latest one.

## 1.0.0 — First public release

- **Nearby file transfer** between Windows PCs, Android phones and tablets,
  and Android TV on the same network — no internet, no cables, no cloud, no
  accounts.
- **Automatic discovery**: your devices appear in your orbit; pair once with
  a verification code, and every connection after that is instant and
  encrypted (TLS).
- **Send anything**: files, folders, photos, videos and APKs, up to 64 GB.
  Transfers pause and resume, and survive a device sleeping, the network
  dropping or the app closing.
- **Device chat** with each paired device, with the full transfer history.
- **Browser Drop**: devices without the app can send and receive from a
  browser on the same network.
- **Wi-Fi Direct** linking between Android devices (Android 13 and up), and
  opt-in Bluetooth discovery.
- **Neervia Remote** for Windows PCs: trackpad and keyboard, live screen
  view, media and volume controls, power actions, quick settings, clipboard
  sync, screen capture, presentation control with a laser pointer, and a
  gamepad.
- **Android app**: optional ads with a one-time Remove Ads purchase; Remote
  widgets beyond the basics unlock with a one-time Remote Unlock purchase.
- **Windows app**: runs in the system tray, with a lightweight resident that
  keeps discovery alive in a few megabytes.
